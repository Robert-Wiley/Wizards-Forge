# Open License Decision

The intent of the Governance Physics Open Research Commons is broad reuse, challenge, reproduction, and extension.

A formal license has **not yet been applied to the existing Wizards-Forge repository**, because doing so would also affect pre-existing code and artifacts.

## Candidate model

A likely dual-license structure is:
- **Research writing, diagrams, schemas, and publishable datasets:** Creative Commons Attribution 4.0 International (CC BY 4.0)
- **Software and executable code:** MIT License

This decision should be made explicitly by the repository owner before applying license files to existing material.

Until then, the public repository is visible, but normal copyright rules still apply.
