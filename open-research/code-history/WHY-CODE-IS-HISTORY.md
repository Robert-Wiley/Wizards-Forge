# Why Code Is Part of the Research History

Governance Physics is not only a collection of prose concepts. Some ideas became executable.

When that happens, code becomes evidence of:
- the interpretation being implemented,
- the variables selected,
- the boundaries imposed,
- the assumptions made,
- and the behaviors actually tested.

Preserving only the newest implementation would erase the evolution of those decisions.

This archive therefore treats historical code the same way the Open Research Commons treats an abandoned hypothesis: not as clutter, but as a record of how the research changed.
